A arte candidata eleva o tronco, apoia as quatro patas e orienta a cabeça à direita. A cauda se abre para manter os cascos visíveis. Referências: `estrategia/reinos/existentes/vaelith/01-gotalume.png` e a pose em pé enviada pelo usuário. A faixa vertical da arte oficial (y=102 até y=761) foi mantida.
