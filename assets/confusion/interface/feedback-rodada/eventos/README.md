# Artes de eventos — amostras

Quatro fundos ilustrados para eventos semanal, quinzenal, mensal e Halloween. PNG 1672 × 941, sem texto.

As folhas de doces, ovos, essências e elementos são referências: os recortes ainda precisam de verificação de bordas, transparência e identificação contra o catálogo oficial. A folha de elementos tem emblemas muito próximos. A arte do card tem fundo no centro e precisa de recorte transparente para sobrepor o Onírico.

Outros temas de ovos, molduras de loja e ícones por raridade seguem pendentes.
