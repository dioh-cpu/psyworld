# Artes de eventos

Quatro fundos ilustrados de eventos semanal, quinzenal, mensal e Halloween. `ovos-individuais/` reúne ovos T1, T2, T4 e T5 de Halloween, Natal, Ano Novo e Páscoa. `doces-individuais/` contém quatro doces de Halloween. `card-moldura-transparente.png` e `moldura-loja.png` são as molduras geradas.

As folhas de referência preservam as artes anteriores. Confira bordas, escala, legibilidade e apresentação em celular ao integrar. Os 18 emblemas de elementos separados estão em `../elementos-glamour/individuais/`.
