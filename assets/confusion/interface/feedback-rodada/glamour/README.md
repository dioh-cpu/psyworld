# Artes glamour

Botões primário, secundário, perigo e cinza: PNGs separados com estados normal, hover, pressionado e desabilitado. Os estados foram gerados a partir da mesma referência e usam quadros de mesmo tamanho; confira o alinhamento e as bordas ao integrar.

`painel-resultados.png` é um painel transparente e `fundo-vitoria.png` é o fundo. `referencia-icones-loot.png` é uma folha ilustrativa; os ícones ainda precisam ser isolados em fundos transparentes antes do uso.

Conferência de enquadramento: todos os 16 PNGs têm 937 × 419. As bordas visíveis variam aproximadamente 1–7 px entre estados gerados; as duas linhas têm posição vertical diferente entre si. O layout deve posicionar por caixa fixa e conferir visualmente a troca de estados em desktop e celular.
