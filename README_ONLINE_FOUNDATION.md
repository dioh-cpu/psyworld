# Conta/cloud save desativados

A inicialização de conta online e o cloud save foram removidos do cliente do PSYWORLD.
O progresso do jogo usa o **Save Local V7**, com auto-resume, backups rotativos em `localStorage` e cópia redundante em IndexedDB.

As APIs de Market/Economia permanecem no projeto para evolução futura, mas não participam do carregamento/salvamento do personagem.
