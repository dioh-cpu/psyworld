# PSYWORLD — Wildlands 3D V143 (teste)

Branch de teste isolada: `test/wildlands-v143`.

Abra **wildlands-v143-test.html** para iniciar diretamente o modo de sobrevivência 3D, sem carregar o menu legado nem o Fast Encounter.

Controles: WASD/setas ou joystick para mover; mouse/toque para câmera; J ataque básico; 1/2/3/4 habilidades; E interagir; B construir; R capturar; F atribuir trabalho; roda do mouse aproxima/afasta; Esc fecha.

O modo contém mundo contínuo, câmera em terceira pessoa, ciclo dia/noite, recursos, crafting, captura, construção de base, NPCs, aliado e criaturas com rigs próprios.
