# Legacy migration bundle

These compact-numbered SQL files were the pre-Supabase-CLI source bundle. They are kept here for history and are not part of the active migration chain.

The active `supabase/migrations/` directory now mirrors the applied `supabase_migrations.schema_migrations` versions from project `otwgavwvjxuwtgncjbiq`. Each active historical file was restored from that migration's stored SQL statements. New migrations use timestamped filenames that match the versions recorded by Supabase.

Do not move these legacy files back into `supabase/migrations/`; doing so makes them look like unapplied migrations to the CLI.
